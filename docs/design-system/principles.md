# Naira Design Principles

## Make readiness feel achievable

Outdoor preparation has many details. Naira turns them into visible, ordered,
and understandable next actions without creating anxiety.

## Calm for discovery, clear for action

Public pages may be spacious and expressive. Planner and admin surfaces favor
clarity, density, and fast recovery. Both use the same tokens and semantics.

## Show the state honestly

Users should know whether something is saved, queued, offline, syncing, blocked,
or in conflict. Never imply success when a mutation is only local.

## Prefer the next useful action

Empty states, errors, filters, and onboarding should explain what happened and
what the user can do next.

## Design for the field

Mobile, touch, slow connections, weather, and interrupted attention are normal
conditions. Readability and recovery are more important than decoration.

## Reuse meaning, not only pixels

Shared components must share behavior, accessibility, terminology, states, and
responsive rules—not only colors and borders.
