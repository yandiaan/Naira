# Architecture Decision Records

Architecture decisions live in this directory and use the template in 000-template.md.

Create an ADR when a decision changes a boundary, provider, dependency direction, data contract, release policy, or operational behavior. Each ADR records context, decision, alternatives, consequences, and the trigger for revisiting it.

The foundation design is documented in ../superpowers/specs/2026-08-20-naira-foundation-design.md.
